**The source code is not public yet.** This repository is only for talking about the mods: tracking issues, collecting ideas and
taking translation fixes. The mods themselves are on mod.io.

## Report a bug

Open an issue with the **Bug report** form. It asks for the mod and its version, the game build, your other mods, the steps, what
happened and what you expected, and the game's log (`stdout.txt`): the log usually shows the cause at once.

## Ask for a feature

Open an issue with the **Feature request** form: which mod, the idea, and why you want it. Look through the open issues first; add a
thumbs-up to an idea you share instead of opening a second one.

## Help translate

The mods ship in the game's 13 languages. A text that reads wrong in yours can be fixed here:

- Small corrections: the **Translation** issue form (language, mod, the current text, a better text).
- Many texts: edit `translations/<language>.json` and open a pull request. See [CONTRIBUTING.md](CONTRIBUTING.md) and
  [translations/README.md](translations/README.md).

You are credited in the mod's patch notes.
